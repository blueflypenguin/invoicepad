# InvoicePad

**Free UK invoice generator for sole traders and freelancers.**

Create unlimited, compliant PDF invoices with a live preview — **no sign-up, no watermark, no account needed**. Your data never leaves your browser.

## Features

- **Unlimited free invoices** — no subscription, no hidden limits
- **Live preview** — see the invoice update as you type
- **Data stays in your browser** — nothing is uploaded to any server
- **UK-ready templates** — VAT fields, CIS notices and trade-specific layouts for 20+ professions
- **No watermark** — clean, professional PDFs you can email straight to a client
- Works on desktop, tablet and phone

→ **[https://invoicepad.co.uk](https://invoicepad.co.uk)**
